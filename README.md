# Vishal Kashyap — Portfolio

A responsive, modern portfolio website built with plain HTML, CSS and JavaScript.

## Structure

```text
vishal-portfolio/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
```

## Easy updates

Search for `UPDATE` or `Replace` comments in `index.html`.

### 1. Profile photo
Replace the portrait image URL in the hero section.

### 2. Social links
Update LinkedIn and GitHub URLs in the Contact section.

### 3. Project links
Replace the placeholder GitHub URLs for Smart Calc and Word Art Generator.

### 4. Background image
Edit `.site-bg` in `css/styles.css`.

### 5. Contact form
The current form opens the user's email client. For production, connect it to:
- Formspree
- EmailJS
- Your own Spring Boot/FastAPI endpoint

## Run locally

Open `index.html` directly, or use VS Code Live Server.

No build step is required.
